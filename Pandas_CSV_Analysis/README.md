# Pandas CSV Reader & Basic Analysis

## Internship

Syntecxhub Data Science Internship

## Project Overview

Pandas CSV Reader & Basic Analysis is a Data Science project developed using Python and Pandas.

The project demonstrates how to read CSV data into a Pandas DataFrame, inspect and analyze the dataset, calculate summary statistics, filter records, select specific columns, perform city-wise analysis, and save filtered results.

## Technologies Used

- Python
- Pandas

## Features

- Read CSV files using Pandas
- Inspect first and last rows
- Check data types
- Generate summary statistics
- Calculate mean, median, minimum and maximum values
- Select specific columns
- Filter records based on conditions
- Perform city-wise employee analysis
- Calculate average salary by city
- Save filtered data to CSV

## Project Files

- `pandas_csv_analysis.py` - Main Python source code
- `employee_data.csv` - Sample employee dataset
- `high_salary_employees.csv` - Filtered employee dataset
- `README.md` - Project documentation

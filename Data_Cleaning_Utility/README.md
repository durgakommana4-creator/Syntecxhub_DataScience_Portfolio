# Data Cleaning Utility

## Internship

Syntecxhub Data Science Internship

## Project Overview

Data Cleaning Utility is a practical Data Science project developed using Python and Pandas.

The project demonstrates how raw customer data can be cleaned and prepared for further analysis by handling missing values, incorrect data types, invalid dates, duplicate records, and inconsistent column names.

## Technologies Used

- Python
- Pandas
- NumPy

## Data Cleaning Operations

- Detecting missing values
- Handling missing values using median and mode
- Converting incorrect data types
- Parsing dates
- Handling invalid dates
- Removing duplicate records
- Standardizing column names
- Generating a cleaned dataset
- Creating a cleaning log

## Output Files

- `cleaned_customer_data.csv` - Cleaned customer dataset
- `cleaning_log.txt` - Record of cleaning operations
